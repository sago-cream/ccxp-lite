# ccxpLite 設計指南

## 設計基礎

| 用途     | 規則                                                     |
| -------- | -------------------------------------------------------- |
| 色彩     | 主要操作與導覽使用紫色；移除與錯誤使用危險色。           |
| 表面     | 內容使用白色，導覽與次要群組使用中性色，以邊框區隔內容。 |
| 字體     | 使用語意字體角色：內文 16px，輔助文字與說明 14px。       |
| 語言     | 支援繁體中文與英文，檢查中文換行及較長的英文標籤。       |
| 數字     | 對齊日期與時間欄位；工讀紀錄使用 Arial 與等寬數字。      |
| 間距     | 重用間距變數。新版面採用 4px 格線，保留既有視覺微調。    |
| 圓角     | 依輸入框、控制項、表面或膠囊形狀選用。                   |
| 動態效果 | 操作回饋維持簡短，以 120ms 為準；遵循減少動態效果偏好。  |

## 重用

- 使用 `@ccxp-lite/tokens` 與 `@ccxp-lite/ui`，優先選用 `--ccxp-lite-text-muted` 等語意名稱。
- 在 `packages/tokens/src/index.ts` 修改變數，再執行 `bun run design:build`，勿手動修改產生的 CSS。
- 不同操作或狀態才新增變體，有第二個使用情境時再抽離元件。
- 原始頁面查找、驗證、送出與導覽留在功能適配器；以 `destroy()` 釋放監聽器與觀察器。

## 舊版頁面

保留原始控制項、名稱、值、表單關聯、事件處理函式與結構樣式。樣式清理留在頁面適配器，避免全面重設。每個 iframe 文件都須安裝樣式與設計變數，並保留元件類別名稱及選擇器順序。

## 狀態與無障礙

輸入框保留可見標籤，純圖示按鈕提供名稱，導覽使用連結。必要指引持續顯示，說明浮窗支援鍵盤與游標操作。對話框須支援 Escape 關閉、焦點限制與焦點還原。

以窄畫面及中英文檢查焦點、停用、展開、載入中、空白與錯誤狀態。共用 UI 變更時同步更新範例，並驗證受影響的 CCXP 頁面。
